An hourly forecast of GTA VI's launch-day Twitch viewers: the shape of 37 past game launches, anchored to hour 1's count, with five quantiles for every hour from 2 to 24.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
